# New Project Startup Checklist

## Before the First Codex Task

- [ ] Copy this standards folder into the new workspace.
- [ ] Attach the approved proposal, objectives, and university template.
- [ ] Complete `00_PROJECT_PROFILE.md` without borrowing facts from another
  project.
- [ ] Decide what is explicitly out of scope.
- [ ] Record available hardware, software, network, budget, and deadline.
- [ ] Identify sensitive-data, safety, legal, licence, and ethical constraints.
- [ ] Create the source, documentation, test, and evidence folders.

## First Codex Task

Use `01_MASTER_SOFTWARE_PROJECT_PROMPT.md`. Require orientation before coding.
Approve only Phase One first.

## Before Implementation

- [ ] Aim and objectives are measurable and map to deliverables.
- [ ] Intended user and primary workflow are known.
- [ ] Stack choices fit the machine and deadline.
- [ ] Architecture and folder boundaries are documented.
- [ ] Test and evidence strategies exist.
- [ ] Environment/secrets strategy exists.
- [ ] Risks and assumptions are logged.

## During Every Phase

- [ ] Implement only approved scope.
- [ ] Run focused and affected integration tests.
- [ ] Record actual results and defects.
- [ ] Update technical documentation.
- [ ] Save sanitised evidence.
- [ ] Update objective traceability.
- [ ] Review phase exit gate and obtain approval.

## Before Academic Writing

- [ ] Software/model/data baseline is stable and verified.
- [ ] Final objectives match completed scope.
- [ ] Repository evidence is indexed.
- [ ] Writing standard has been customised and locked.
- [ ] Research date window and citation style are confirmed.
- [ ] Source register and master reference file exist.
- [ ] Chapter One begins only after project orientation is approved.

## Before Final Submission

- [ ] All chapters approved individually.
- [ ] Front matter approved separately.
- [ ] Reference list filtered, deduplicated, reciprocal, and alphabetised.
- [ ] Complete report compiled into a new file.
- [ ] Fields, contents, captions, and pagination updated.
- [ ] Personal/institutional placeholders removed.
- [ ] Every page visually reviewed.
- [ ] DOCX approved before PDF export.
